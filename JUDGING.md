# Judging Criteria Notes

## Best Open-Source AI Project (Track B)
- **Meets Requirements**: Must be open-source (GitHub + Apache 2.0/MIT) and integrate an open-source/open-weight model (Gemma 4).
- **Format**: Must be an Agent Skill, LLM app, or Model Harness.
- **Problem Solving**: Solves a clear problem effectively.
- **Substantial Work**: Shows significant technical implementation (e.g., deterministic rules engine + LLM perception).
- **Working Demo**: Flawless live demo (use fallback mode if API fails).
- **Explanation**: Clear `README.md` explaining architecture and decisions.

## Best Use of Gemma 4 (Track A)
- **Model Usage**: Demonstrates a deep integration of Gemma 4 (multimodal capabilities are a huge plus).
- **Category Fit**: Learning, Creativity, Productivity, or Community tool.
- **Impact**: Solves a real user need.
